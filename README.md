### Featured projects

**[Cohort Analytics — Student-Progress ETL](https://github.com/Bharath-Naveen/cohort-analytics)**
Contributed to the ETL pipeline behind a University of Arizona student-progress analytics platform — Julia ETL on AWS ECS/Fargate → DynamoDB → Lambda API → Vue dashboard — classifying degree progress as On Track / Behind / Ahead.

**[BN Motors — Relational Database & Analytics](https://github.com/Bharath-Naveen/bn_motors_SQL)**
A full dealership data model (26-table ER schema) with advanced analytical SQL and reusable reporting views for decision-makers.

**[Phishing Detection Dashboard](https://github.com/Bharath-Naveen/containerized-phishing-project)**
A layered detection pipeline — ML URL triage, live browser capture (Playwright), DOM/behavior signals, and a deterministic adjudication layer — containerized with Docker and surfaced through a Streamlit dashboard that renders plain-language verdicts.

**[Loan Default Prediction](https://github.com/Bharath-Naveen/german-loan-default-ml-)**
End-to-end ML on imbalanced credit data: EDA, preprocessing, and benchmarking five classifiers (Logistic Regression → Gradient Boosting) with a focus on recall and F1.
