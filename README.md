## Featured work

Each project leads with the problem it solves. Repo links are inline; deeper writeups are on [bharathnaveen.com](https://bharathnaveen.com).

**[Phishing Detection System](https://github.com/Bharath-Naveen/containerized-phishing-project)** — Catches fake and malicious websites the moment they appear and returns a clear safe / suspicious / phishing verdict with the reasoning behind it. Containerized and deployed on AWS.
`Python` `LightGBM` `XGBoost` `Playwright` `Docker` `AWS` `Streamlit`

**[Cohort Analytics Platform](https://github.com/Bharath-Naveen/cohort-analytics)** — A production analytics platform that shows university advisors whether student cohorts are on track, behind, or ahead of pace. I built the serverless AWS data and ETL layer end to end.
`AWS Lambda` `DynamoDB` `Julia ETL` `CI/CD`

**[YouTube Comment Spam Detector](https://github.com/Bharath-Naveen/youtube-comment-spam-detector)** — Flags harmful YouTube comments (phishing scams, bait bots, engagement spam) and sorts them by type, tuned for high precision on the ones that matter.
`Python` `NLP` `TF-IDF` `scikit-learn`

**[AutoRisk](https://github.com/Bharath-Naveen/AutoRisk)** *(in progress)* — A reliability score for cheap used cars, pulling NHTSA complaints and recalls to flag which budget cars are actually safe bets.
`Python` `XGBoost` `NLP` `Streamlit`
